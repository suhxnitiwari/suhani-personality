# Suhani ✦ Soft heart. Strong spirit.

**[Open the site →](https://suhxnitiwari.github.io/suhani-personality/)**

Ten personality assessments, one person. This site takes my results from CliftonStrengths, VIA, 16Personalities, Enneagram, DISC, Holland, Big Five facets, love languages and more, and turns them into an interactive story about who I am, how I love, what drives me and what I build.

## What's inside

Twenty sections across four acts:

| Act | Question | Sections |
|---|---|---|
| I · Suhani | Who is she? | Inside her head (a brain you pull apart), strong spirit, soft heart, both/and contradictions, signature strengths, in a word |
| II · Love | How does she love? | Inside her heart (a beating 4-chamber heart), inner circle, love language, mood meter, icks, would we click? |
| III · Mind | What drives her? | Values, photos, where she'd thrive, absolutely not, ask the data, quiz |
| IV · Built | What did she build? | Colors & fonts (every color traced back to a test result), final test |

## Details I like

- **Receipts for every claim.** Each trait links back to the actual score that supports it, plus how much research stands behind each test.
- **15 achievements** to unlock by playing with the page.
- **Holi paint hero.** The canvas splashes only use colors from my results, so nothing is random.
- **Shareable sections.** Every section has its own link (for example `/icks/` or `/love-language/`), and `?view=<section>` shows it on its own.
- **No frameworks.** It's one hand-built HTML file with vanilla JS, CSS and canvas, set in Playfair Display and DM Sans.

## Run locally

```bash
git clone https://github.com/suhxnitiwari/suhani-personality.git
cd suhani-personality && python3 -m http.server
```

Then open http://localhost:8000.
